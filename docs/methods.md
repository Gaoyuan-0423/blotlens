# 截图趋势检查的方法

本工具从论文截图的可见像素估计暗色 WB 条带的相对强度，辅助人工作趋势比较。一个柱子表示一条截图泳道的测量；不自动赋予生物学重复数，不生成误差线、P 值、显著性符号或“一致／不一致”判定。原论文柱状图只作为旁边的视觉参考。

## 输入和识别

首版处理一个 WB 面板及可选的原论文柱状图，接受 PNG/JPEG。JPEG 的 EXIF 方向必须为 1 或未指定；含旋转／镜像方向元数据的文件需要先另存为 PNG 截图，避免浏览器显示坐标与模型接收图像的坐标不同。图像由浏览器按实际解码尺寸读取；这不是原始仪器像素或高位深定量管线。导入、手动框选、积分与导出在本机完成。点击整图识别时发送完整截图；点击「识别框选区域」仅发送当前 WB 选区（按原尺寸裁剪为白底 PNG）。图片通过本机代理发送至用户配置的视觉服务；本地运行不等于图片始终不出本机。

视觉模型只输出蛋白名称、组别、面板边界、泳道和候选矩形，以及内参／对照建议和文字警告。坐标必须是相对于发送图片全尺寸的 0–1 分数。模型不提供强度数值，不读取论文柱高作为积分结果，不补造缺失泳道。返回值经结构、ID、配对及坐标检查后成为待核对草稿。

归一化坐标转换为整数像素矩形后，同一蛋白行的框采用一致宽高（候选框的最大宽高），保留各自中心。局部暗像素质心只允许最多框宽／高 15% 的位移；边界限制在 WB 区域。背景候选从条带上下邻近位置寻找，排除与条带重叠、明显不均匀或过暗的区域。初始识别响应与后续编辑历史都保留在分析 JSON 中。

这些定位与背景选择是可编辑启发式，不是经校准的置信度或已验证的最优区域。扣背景模式没有合适候选时需人工指定背景；可以显式切换到不扣背景模式查看快速趋势，不能把缺失背景静默当作零。补齐缺失背景保留已有框，原候选失败后才尝试同列较短或较薄的区域，仍避开条带与面板边缘，并要求总面积至少为 max(8, 条带面积的 20%)。黑框、文字、水印和紧邻条带都可能造成错误，检查叠加框比只看重建柱状图更重要。

## 像素与计算

当前算法版本为 `screenshot-density-1`。读取浏览器解码后的 RGBA，先按 alpha 在白色上合成每个 RGB 通道，然后取：

```text
G = round(0.299 × R + 0.587 × Gchannel + 0.114 × B)
S = 255 − G
bandSum = sum(S in band rectangle)
backgroundMean = mean(S in union of background rectangles)
net = bandSum − bandArea × backgroundMean
ratio(lane) = targetNet(lane) / referenceNet(lane)
relative(lane) = ratio(lane) / ratio(controlLane)
```

矩形采用整数起点与宽高，包含左上边界，不包含 `x + width`、`y + height`。背景矩形重叠的像素只计算一次；与任何条带重叠的背景被判为不可用。显示缩放、图表配色不改变计算像素。RGB 系数和白底合成只是固定截图转换约定，不是对相机线性响应的校正。

内参按照蛋白行与泳道 ID 配对，随后使用单条对照泳道归一化。新布局默认选择条带横坐标中位数最小的泳道，用户可以修改；导入文件保留保存的对照，不按标签重新猜测。`controlLaneMode` 记录自动最左或人工选择；缺省旧文件按人工选择保留。重新识别仅在旧、新泳道中该名称均唯一且完全相同时沿用明确选择，否则回到新布局的最左默认；明确清空的对照仍为空。框的位置／尺寸、背景、内参或对照修改后重新计算，并将人工复核状态取消。同一行更改条带尺寸会同步该行尺寸，防止因各泳道取样面积不同引入额外偏差。

负净值在明细中保留，不取绝对值或截断为零。目标净值非正、内参缺失或非正、对照不可用时，相应相对值为空并标注原因，不通过增加很小的分母常数生成数值。背景不足／不均匀可触发取样提醒。另计算灰度 ≤1 的像素比例 `nearBlackFraction`（0–1），CSV 写入 `near_black_pixel_fraction`。界面仅将比例至少 1% 的条带汇总为可选折叠信息，该显示门槛不代表饱和或截断判据；黑色可能是条带正常外观，不逐行报警，也不影响计算。原始曝光与动态范围不能仅凭截图确定。

## 可选的快速趋势与重叠容差

分析设置 `measurementPolicy.backgroundMode` 为 `subtract`（默认）或 `none`。`none` 使用 `bandSum` 作为目标和内参信号，继续按同泳道内参、单条对照归一化，背景均值留空。实现中的 `net` / `referenceNet` 字段在此模式表示参与归一化的原始信号；UI 和 CSV 用“未扣背景信号”/`raw_signal_for_normalization`、`reference_raw_signal` 明示，图表显示“快速趋势 · 未扣背景”。这不等同于 ImageJ 中已画基线的峰面积。零信号分母仍无效；模式切换不更改任何取样框。

`measurementPolicy.maxBandOverlapFraction` 记录可选同行重叠容差（0 或 0.1）。每个条带框与同行其他框的交集取并集，再除以该框面积；超过容差或跨行重叠使对应值无效。容差内仍按原矩形积分，共享像素会被分别计算，显示提醒；不拆分或猜测相连条带的边界。新文件默认 0.1，旧文件没有该设置时为 0。10% 是软件容差，尚未验证为科学准确性阈值。背景与条带相交在扣背景模式中仍无效。

上述策略随分析文件和操作记录保存，CSV 逐行写入 `background_mode` 与 `max_band_overlap_fraction`；旧文件缺省策略为扣背景且不允许重叠。算法版本仍为 `screenshot-density-1`，具体计算须同时参考这些显式策略。

## 解释范围

截图可能经过缩放、JPEG 压缩、对比度调整、非线性变换及多张条带拼版；背景也可能含水印。因此当前图像灰度不保证与原始蛋白量成正比。目标与内参的实验对应关系也不能仅凭画面完全确定。代表性 WB 图片的单次可见结果与跨重复汇总图之间的差别，不能单独证明论文结果错误或图像不当处理。

本工具可帮助定位值得进一步核查的趋势。正式结论仍需要原始未裁剪图、曝光信息、独立重复和作者的分析流程。首版不跨膜／跨曝光合并、不恢复丢失动态范围、不进行伪造检测，也不评判科研诚信。

## 可复现记录

分析 JSON 包含原始截图、SHA-256、实际像素矩形、背景、标签／配对、算法版本、识别服务地址／模型／提示词版本、原始识别响应及编辑历史。选区识别另保存 `recognition.inputRegion`（原图整数像素），模型原始响应仍相对于该选区；保存的取样框则已映射为原图坐标。API key 不导出。重新计算依赖算法版本和记录的像素；模型名称与提示词版本不能保证未来重跑得到相同的候选区域，因此原始响应也保留。

CSV 保存原始积分、面积、背景、净信号、内参信号与归一化值，空值不得理解为零。PNG/SVG 是便于核查的派生图，分析 JSON 才保留完整设置。导出的 JSON 含论文截图，分享前应按原稿使用约定处理。

方法参照：[ImageJ 的 ROI 测量定义](https://imagej.net/ij/docs/guide/146-30.html)；本项目与 ImageJ 的固定 ROI 检查见 [validation.md](validation.md)。这里只对齐已说明的数学定义，未声称不同背景算法天然等价。

## 手工编辑后的检查记录

每次编辑按当前原图像素、条带框和背景框重新计算。已被手工定位取代的初始化定位提示会从当前提醒中移除；扣背景模式中缺失或无效背景仍阻止相应计算，背景不均匀等实测取样提醒仍保留。深黑像素只在可选信息中显示，不作为异常。界面将模型／建框时的原始备注折叠保存用于追溯，不作为实时检查结果。CSV 的 `warnings` 为当前测量提醒，末尾的 `recognition_notes` 为原始备注。显示缩放不改变坐标单位、取样像素或测量值。
